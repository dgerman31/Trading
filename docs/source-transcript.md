## The core idea in one line

At the New York open, wait for price to **sweep the Asia or London session high/low**,
then on the **1-minute chart** enter the **fair value gap (FVG) that forms on the reversal**,
put the **stop at the swing point made by the sweep**, and **target the next liquidity pool**
(at least 1:2 reward:risk).

Everything else in this repo (rules, risk, filters, management, backtesting) is built
around that core so it can be traded and tested mechanically. The reel itself gives
only the core; the added detail is ours, not the creator's.
